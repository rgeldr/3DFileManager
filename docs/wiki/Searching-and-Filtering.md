# Searching and Filtering

The toolbar narrows the file list. File counts in the File Types and Tags menus follow the current search, creator, and folder scope.

## Search

Type in **Search**. Each word matches the start of a word in the sort name, original file name, creator, notes, or tags. Press Escape while the search box is focused to clear the text.

**Current folder** limits the list to the folder open in the tree. **Entire library** searches every folder. The choice is saved.

## File types

Open **File Types** and check the extensions you want. The list is the extensions present in the current results, with a count for each. **Select none** clears the type filter.

## Tags

Open **Tags** and check one or more tags.

- **Any** shows files that have at least one of the checked tags.
- **All** shows files that have every checked tag.

**Clear** inside the menu unchecks the tags.

## Creator and sort

**Creator** limits the list to one creator, or **All creators**.

**Sort** orders the list by sort name, size, date modified, date added, or creator. In Details view, clicking a column header sorts by that column and a second click reverses it.

## Clear

**Clear** next to the search box is enabled while search, file types, tags, or creator is set. It clears all four. It does not change the folder, the sort, or Current folder / Entire library.

When file types or tags hide every file, the empty grid also shows **Clear filters**. That button clears the file type and tag selections and leaves search, creator, sort, and scope as they are. Search or creator alone can also produce “No files match the current filters”; in that case the empty-grid button is hidden and the toolbar **Clear** is the control that resets them.

An empty folder with no filters shows “This folder is empty. Drop files here to import them.”
